# Лендинг «Ковалёв и партнёры» — шаблон

Next.js 16 (App Router, Turbopack) · TypeScript 7 · Tailwind CSS 4 · без UI-библиотек.

Проект собран как **база под будущие лендинги**: вся визуальная система живёт
в токенах, весь контент — в одном конфиге, секции подключаются массивом.

---

## Запуск

```bash
npm install
```

```bash
npm run dev
```

`cp .env.example .env.local` — если нужна реальная отправка формы.
Без env форма работает и печатает заявку в лог сервера.

## Что где лежит

| Путь | Ответственность |
|---|---|
| `theme/tokens.css` | **Все** визуальные значения: палитра, шкала, ритм, радиусы, движение. Единственное место с hex |
| `theme/palette.ts` | Те же цвета для мест без CSS: favicon, OG-картинка, `themeColor` |
| `app/globals.css` | Маппинг Tailwind на переменные (`@theme inline`) + база и reveal |
| `content/site.config.ts` | Бренд, контакты, SEO, аналитика, массив секций. **Единственный файл под замену на новом проекте** |
| `types/site.ts` | Формы данных всех секций |
| `components/ui/` | Button, Card, Input, Accordion, Toast, Container, Section, SectionHeader, RevealRoot |
| `components/sections/` | Hero, Stats, Features, Steps, Gallery, Testimonials, Team, FAQ, Pricing, CTA, ContactForm, Footer |
| `components/SectionRenderer.tsx` | Реестр: тип секции → компонент |
| `app/api/contact/route.ts` | Приём формы: Telegram + email, антиспам, фолбэк в лог |
| `lib/seo.ts` | Metadata, JSON-LD (Organization + LegalService), навигация из секций |

### Добавить новую секцию

1. Тип и интерфейс в `types/site.ts`, добавить в юнион `Section`.
2. Компонент в `components/sections/`.
3. Строка в реестре `components/SectionRenderer.tsx`.
4. Объект в `sections` внутри `content/site.config.ts`.

Больше нигде ничего подключать не нужно.

## Дизайн-система

Это не просто стилевые предпочтения — если эти правила нарушить, макет
начинает разваливаться и выглядит как обычный шаблон.

Акцент (`#14452F`) — только в шести местах: primary-кнопка, заливка
единственного CTA-блока, текстовые ссылки в контенте, focus-ring, активные
состояния (открытый аккордеон, активный пункт меню) и знак логотипа. Больше
нигде — не на иконках, не на номерах разделов, не на цифрах статистики, не на
заголовках, линейках, рамках карточек, бейджах и hover-подсветке. Иконки
всегда `--color-fg-muted`, цифры — `--color-fg` или `--color-rule-strong`.

По всему проекту: без теней, без градиентов, без декоративной графики
(кружки, диагонали, перекрывающиеся фигуры), радиус максимум 4px, эмодзи
не используем.

**Поверхности.** У каждой секции есть `data-surface` (`paper` / `surface` /
`ink` / `accent`), всё внутри само подхватывает цвета через `--surface-*` —
компонентам не нужно знать, какая сейчас тема или фон. Порядок на странице:
`paper → paper → surface → paper → ink → surface → paper → accent → surface`.
Тёмный блок один (кейсы), акцентный тоже один (CTA).

**Шрифты.** Source Serif 4 — заголовки, крупные цифры, цитаты. Golos Text —
всё остальное. Третьего шрифта нет и не планируется. Курсив — только для
ссылок на нормы права (`.legal-ref`).

## Тёмная тема

`theme.darkModeToggle: false` — кнопки нет, сайт рендерится в `defaultMode`.
Токены тёмной темы в `tokens.css` при этом рабочие: переключить флаг в `true`
достаточно, чтобы получить кнопку, `data-theme` на `<html>`, сохранение в
`localStorage` и анти-вспышку. На этом проекте выключена намеренно — для
юридической тематики тёмная тема не работает на доверие.

## Форма

`POST /api/contact` → Telegram и email (Resend), оба канала независимы.
Если env не заполнены — заявка печатается в лог сервера, ничего не падает.

Антиспам: honeypot-поле `company` + минимальное время заполнения (3 с) +
ограничение 5 запросов в минуту с адреса. Боты получают `200 OK` и молча
отсеиваются.

## SEO

`robots.txt`, `sitemap.xml`, canonical, JSON-LD (Organization + LegalService),
OG-картинка через `next/og` (шрифты подтягиваются с Google Fonts, при ошибке
сети отдаётся SVG-фолбэк того же макета), favicon из `theme.faviconGlyph`.

Яндекс.Метрика: `analytics.yandexMetrikaId` — `null` означает, что скрипта на
странице нет вообще.

## Новый проект из шаблона

```bash
npm run new-project my-client
```

Копирует базу в `../my-client`, обнуляет `site.config.ts` до каркаса, правит
`package.json`. Палитра и шрифты не трогаются — их меняют руками под бренд.

## Известное

**TypeScript 7** — новый нативный (Go-based) компилятор, он не отдаёт старый
JS compiler API, на который опирается штатная проверка типов в `next build`.
Поэтому в [next.config.ts](next.config.ts) включён
`experimental.useTypeScriptCli: true` — это официальный путь Next.js для TS7,
а не обходной хак; сам build без флага прямо укажет на него в ошибке. Если
для продакшена важнее стабильность инструментария, а не самая свежая версия
TS, — самый безопасный откат: `typescript@6.0.3` и убрать флаг из конфига,
без других изменений в коде.

`npm audit` показывает 3 high в транзитивных зависимостях самого Next
(`postcss`, `sharp`) — advisory по факту зацепляет диапазон версий Next
целиком, включая текущую. `npm audit fix --force` откатывает на `next@9` —
делать этого нельзя. Закроется апстримным обновлением Next.
